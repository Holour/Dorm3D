# 建模依据与待确认

> 首版所需确认现已完成。下文保留初始校核过程；最终决策见 `用户确认记录.md`，模型与检查结果见 `项目进展.md`、`验收记录.md`。

建模对象：北京邮电大学学生十公寓宿舍。长度记录均为 cm。原始数据保留在 `寝室空间尺寸.md`，不直接覆盖手工测量结果。

## 来源规则

- **手工测量**：尺寸文档明确记录的数值。
- **照片可见**：仅支持形态、连接关系和材质识别，不等同于精确测量。
- **计算推导**：由其他尺寸计算得出，必须保留计算前提。
- **用户确认**：后续补充或对原记录的修正，应单独记录。
- **待确认**：证据不足或相互冲突，不擅自确定。

## 已提交用户核对的关键关系

1. **长度口径**：660 是否为不含阳台的室内净长？三床长合计 570，若不含阳台，剩余 90 仍包含端部间隙、床架外尺寸和床间间隙，不能直接等分。
2. **层高口径**：165 + 100 = 265，仅在两项均以同一床面为基准时成立。
3. **横向闭合**：330 − 200 − 2 × 58 = 14，若对称且桌面方向无误，每侧桌背到墙为 7；(330 − 110) / 2 = 110 是对称假设下梯子相应测量面到墙的距离。再结合柜内深 56 与板厚，可能与梯柜距 38–40 不闭合，需核对测量面、对称性及优先级。
4. **床号与位置**：照片支持两列三床，但没有可靠的完整编号对应；需确认入口面向阳台时左右床号及两端留空。
5. **桌柜组合**：91 的桌长是否包括侧书柜？书柜 55 × 26 的方向需要确认，不能简单将衣柜、桌子、书柜尺寸沿床长相加。
6. **缺测细节**：门窗、空调、暖气、椅子、框架管径、柜板厚度等缺少完整尺寸。近似建模须用户允许，且估算应明确标识。

## 复核注意

- 衣柜 71 − 41 − 28 = 2，可能对应中隔板厚度；没有证据表明这三项必然矛盾。
- 衣柜四区高度之和为 142，与 150 相差 8，可能包括层板或测量误差；未经确认不平均分配差值。
- 书柜三层高度之和为 78，不等于已知外高；记录没有说明编号方向与板厚。
- 原始尺寸已整理为 `原始尺寸参数.json`。未知字段保留 `null`，不以零代替，也不补入默认布局。
- 当前没有不依赖布局假设就必然成立的硬矛盾；横向距离需要先统一测量边界。
