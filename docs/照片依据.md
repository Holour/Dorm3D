## 可直接用于建模的结构依据

1. 室内中央为通道，两侧沿通道连续布置上床下桌柜组合；红褐色入口门与白色框玻璃门窗位于照片所示通道的两端。
2. 家具具有浅灰色涂装金属床架、木色床板及黄褐色木纹桌柜；床架包含立柱、横梁、栏杆和通道侧梯子。
3. 两张完整家具正面图均呈现衣柜在画面左、书桌在画面右的组合；书桌包含上方长搁板、侧层架、抽拉板、抽屉和下方开敞格。这是这些照片内家具的证据，尚不足以自动推广到所有床位。
4. 打开的衣柜显示了搁板区与挂衣区；床板底部的支撑构件有明确近景。
5. 室内白墙、白顶、浅色方形瓷砖、黑色踢脚线，以及门窗端的空调和散热器均有照片依据。
6. 插座、软包、蓝色贴面、窗帘及表面磨损可用作后续细化参考；照片尚未给出它们在统一坐标系内的位置和完整范围。

## 仍需确认的关系

- 统一方向约定：从入口面向玻璃门窗时，各床号属于哪一侧、从近到远如何排列。
- 每张家具近景与床号的对应关系，以及两侧床位的衣柜／书桌是否同向、镜像或存在个别差异。
- 各梯子与床位的归属、梯子在各床位端部的具体位置及是否共用。
- 两张间隙近景分别对应哪张床、哪面墙及哪组测量值；净空应以墙面、踢脚线、床架还是柜板作为测量边界。
- 门窗、空调、散热器、灯具与插座的尺寸和定位；照片中的遮挡部分、室外区域及门窗完整分格不能自行补成确定布局。
- 需要表现的是哪一日期的陈设状态，以及椅子、窗帘、软包、贴面和临时物品是否纳入模型。

几何尺寸与布局应以用户提供并核对后的记录为准；照片用于核对形态、材质外观和可见相对关系。存在冲突时保留未确认标记，不用透视观感覆盖测量记录。
